# Basic Python Chatbot

A simple rule-based chatbot developed using Python as part of my **CodeAlpha Python Internship**.

This project demonstrates fundamental Python programming concepts by creating an interactive command-line chatbot that responds to greetings, common questions, and simple user messages.

## Features

- Responds to common greetings such as Hello, Hi, and Hey
- Answers basic questions
- Provides simple information about Python
- Responds to common messages such as Thanks and Good Morning
- Includes a Help option
- Allows the user to exit using `bye`
- Handles unknown messages with a default response

## Technologies Used

- Python
- User Input
- If-Elif-Else
- While Loop
- String Methods

## How It Works

The chatbot takes input from the user and processes the message using Python string methods.

It then checks the input using `if-elif-else` conditions and provides a predefined response.

The chatbot continues running until the user types `bye`.
